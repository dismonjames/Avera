Ví dụ Mã nguồnCode Examples

Các chương trình mẫu thực tế được lấy trực tiếp từ thư mục examples/ của repository.Working programs taken directly from the repository's examples/ directory.

1. Hello World

hello.av
#std.io

action main(): I32 will
    print("Hello from Avera")
    return 0
finish

2. Tính dãy Fibonacci (dùng vòng lặp while)Fibonacci Sequence (while loop)

Chương trình thực tế từ examples/fib.av. Chú ý cách khai báo biến bằng : và compound assignment +=:

Actual program from examples/fib.av. Notice variable declaration with : and compound assignment +=:

fib.av
#std.io

action main(): I32 will
    :a = 0
    :b = 1
    :t = 0
    :i = 0
    while i < 10 will
        t = a + b
        a = b
        b = t
        i += 1
    finish
    print("fib(10) =", a)
    return 0
finish

3. FizzBuzz

Chú ý: if/else if/else chỉ có một finish duy nhất ở cuối:

Note: the entire if/else if/else chain has only one finish at the end:

fizzbuzz.av
#std.io

action main(): I32 will
    for i in 1..17 will
        if i % 15 == 0 will
            print("FizzBuzz")
        else if i % 3 == 0 will
            print("Fizz")
        else if i % 5 == 0 will
            print("Buzz")
        else
            print(i)
        finish
    finish
    return 0
finish

4. Magnet Pointer — đọc địa chỉ bộ nhớMagnet Pointer — read memory address

magnet.av
#std.io

action main(): I32 will
    :value = 42
    ~m = value
    print("Value:", value)
    print("Address:", ~m.address)
    return 0
finish

5. Shape (Struct) và MethodShape (Struct) and Method

shape.av
#std.io

shape User will
    name: Text
    age:  I32
finish

action User.greet(u: User): I32 will
    print("User:")
    print("name:", u.name)
    print("age:", u.age)
    return 0
finish

action make_user(n: Text, a: I32): User will
    :u = User(n, a)
    return u
finish

action main(): I32 will
    :me = make_user("Alice", 30)
    me.greet()
    return 0
finish
