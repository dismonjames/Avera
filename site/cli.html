Lệnh CLI & Công cụ (CLI & Tools)CLI Commands & Tools

Trình biên dịch Avera cung cấp 4 lệnh CLI cốt lõi giúp bạn quản lý từ lúc kiểm tra mã nguồn cho đến khi ra file thực thi chạy được.

The Avera compiler provides 4 core CLI commands for everything from checking code to building the final executable.

1. avera run <file>1. avera run <file>

Lệnh tiện lợi nhất. Nó sẽ biên dịch (compile) + liên kết (link) + chạy ngay lập tức.

The most convenient command. It will compile + link + run immediately.

Terminal
avera run main.av

2. avera build <files...>2. avera build <files...>

Biên dịch mã nguồn ra mã máy (Cranelift IR -> .o object file) rồi gọi C Linker để tạo file thực thi native. Nếu có .mav thì ném file .mav vào đây.

Compiles source code to machine code and invokes the C Linker to create a native executable.

Terminal
avera build main.av
avera build src/sys.mav src/core.mav

3. avera check <files...>3. avera check <files...>

Chỉ chạy Lexer, Parser, và Ownership/Borrow/Magnet Checker (Static Dataflow Analysis). Không sinh mã máy (Cranelift). Cực kỳ nhanh, lý tưởng để dev check lỗi liên tục.

Runs frontend and static safety checks without generating machine code. Extremely fast, ideal for continuous checking during development.

Terminal
avera check project.mav

4. avera explain <CODE>4. avera explain <CODE>

Tra cứu chi tiết về một mã lỗi (Diagnostics) do compiler ném ra. Giải thích nguyên nhân và cách sửa chuẩn xác.

Look up detailed information on an error code emitted by the compiler, including causes and solutions.

Terminal
avera explain E4001
avera explain EMagnetTargetMoved
