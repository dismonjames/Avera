Thư viện chuẩn (Stdlib)Standard Library

Các hàm và kiểu dữ liệu chuẩn được cung cấp bởi compiler runtime. Không cần định nghĩa lại — chỉ cần import đúng module.Functions and types provided by the compiler runtime. No need to redefine them — just import the correct module.

Ghi chúNote

Trong Avera v0.1.0, tất cả hàm stdlib là built-in — được trình biên dịch inject trực tiếp vào, không phải hàm Avera thông thường. File core.av và io.av trong stdlib/ chỉ chứa comment giải thích, không có khai báo hàm.

In Avera v0.1.0, all stdlib functions are built-in — injected directly by the compiler, not regular Avera functions. The core.av and io.av files only contain explanatory comments, not function declarations.

Module #std.ioModule #std.io

Import bằng dòng #std.io ở đầu file. Cung cấp các hàm I/O terminal:

Import with #std.io at the top of the file. Provides terminal I/O functions:

io_demo.av
#std.io

action main(): I32 will
    print("xin chao")               # in ra stdout, tự xuống dòng
    write("khong xuong dong ")      # in ra stdout, KHÔNG xuống dòng
    eprint("day la loi!")           # in ra stderr
    :line = input()                 # đọc 1 dòng từ stdin
    print("ban nhap:", line)
    return 0
finish
