Trình Biên Dịch Ngôn Ngữ AveraThe Avera Programming Language

Avera là ngôn ngữ lập trình hệ thống biên dịch trực tiếp ra mã máy (AOT) sử dụng Cranelift backend, cơ chế kiểm tra Ownership qua phân tích luồng dữ liệu MIR tại thời điểm biên dịch, và hệ thống con trỏ Magnet đặc thù.Avera is an ahead-of-time (AOT) native systems language compiled to machine code via Cranelift, with compile-time memory safety enforced through MIR dataflow analysis and a unique Magnet pointer discipline.

Sơ đồ pipeline biên dịchCompiler Pipeline

.av source → Lexer (token stream) → Parser (AST) → Resolver (name resolution) → TypeChecker → Ownership+Borrow+Magnet check (MIR) → Drop Elaboration → Cranelift IR → .o → Linker → native binary

Toàn bộ quá trình này xảy ra một lần, không có Garbage Collector, không có Virtual Machine.

This entire pipeline runs once per program. There is no garbage collector and no virtual machine.

Biên dịch AOT nativeAOT Native Compilation

Cranelift sinh file object .o từ IR, sau đó hệ thống C linker (cc) liên kết thành file thực thi. Không cần VM hay GC.

Cranelift emits .o object files from its IR. The system C linker (cc) produces the final binary. No VM or GC.

Ownership & Drop xác địnhDeterministic Ownership & Drop

Biến chuyển qua các trạng thái Uninit → Init → Moved/Dropped. Drop Elaborator chèn lệnh giải phóng chính xác vào CFG trước khi sinh mã.

Variables move through states Uninit → Init → Moved/Dropped. Drop Elaborator inserts precise deallocation into the MIR CFG before codegen.

Con trỏ Magnet (~)Magnet Pointer (~)

Con trỏ ~m gắn vào địa chỉ runtime thực của một biến. Trình biên dịch kiểm tra tĩnh để đảm bảo magnet không trỏ vào vùng nhớ đã bị move hay drop.

A ~m magnet pointer attaches to the live runtime address of a variable. The compiler statically verifies it never points to a moved or dropped location.
