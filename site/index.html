Trình Biên Dịch Ngôn Ngữ Avera The Avera Compiler Documentation

Avera là ngôn ngữ lập trình hệ thống native AOT, được xây dựng trên Rust với backend Cranelift, cơ chế Ownership kiểm tra luồng dữ liệu và con trỏ Magnet đặc thù. Avera is a stage-0 AOT native systems programming language written in Rust with Cranelift codegen, compile-time ownership tracking, and Magnet pointers.

Kiến trúc cốt lõiCore Architecture

AOT NativeAOT Native

Biên dịch mã nguồn thành file object native .o thông qua Cranelift backend và liên kết trực tiếp bằng C linker của hệ thống.

Compiles source code to native object files using Cranelift IR and links directly with system C linker.

Magnet PointerMagnet Pointer

Con trỏ Magnet ~m gắn trực tiếp với địa chỉ runtime thực tế, cho phép thao tác con trỏ an toàn và truy xuất địa chỉ bộ nhớ.

Magnet pointers ~m attach to live runtime memory addresses and allow explicit machine address inspection.

Ownership CheckOwnership Check

Phân tích luồng dữ liệu MIR tự động bắt các lỗi move/drop bộ nhớ và giải phóng tài nguyên xác định không cần Garbage Collector.

MIR dataflow analysis verifies memory move and drop states automatically without requiring a Garbage Collector.

Cài đặt & Khởi chạyQuickstart & Installation

Biên dịch từ mã nguồnBuilding from Source

Yêu cầu môi trường có cài đặt Rust (edition 2021) và C linker (cc/gcc/clang) trên PATH hệ thống.

Requires Rust (edition 2021) and a system C linker (cc/gcc/clang) available on PATH.

Terminal
git clone https://github.com/dismonjames/Avera.git
cd Avera
cargo build --release

Chương trình đầu tiênFirst Program

Tạo file hello.av:

Create file hello.av:

hello.av
#std.io

action main(): I32 will
    print("Xin chao, Avera!")
    return 0
finish

Biên dịch và thực thi ngay lập tức:

Compile and run immediately:

Terminal
./target/release/avera run hello.av

Cú pháp Ngôn ngữLanguage Syntax

Khai báo Hàm (Action)Function Declarations (Actions)

Mọi hàm trong Avera được định nghĩa bằng từ khóa action và sử dụng cặp will ... finish cho khối lệnh:

Functions in Avera are defined using the action keyword with will ... finish block scopes:

Syntax
action add(a: I32, b: I32): I32 will
    return a + b
finish

Biến và Vòng lặpVariables & Loops

Example
#std.io

action main(): I32 will
    let sum: I32 = 0
    let i: I32 = 1

    while i <= 10 will
        sum = sum + i
        i = i + 1
    finish

    print("Sum 1..10 = ", sum)
    return 0
finish

Ownership & Con trỏ MagnetOwnership & Magnet Pointers

Con trỏ Magnet ~m cho phép gán trực tiếp tham chiếu tới vùng nhớ runtime thực sự:

Magnet pointers ~m bind directly to runtime memory addresses:

magnet.av
#std.io

action main(): I32 will
    let value: I32 = 100
    let ~m = value

    print("Value:", value)
    print("Address:", ~m.address)
    return 0
finish

Mã nguồn Ví dụCode Examples

fib.av
#std.io

action fib(n: I32): I32 will
    if n <= 1 will
        return n
    finish
    return fib(n - 1) + fib(n - 2)
finish

action main(): I32 will
    print("fib(10) =", fib(10))
    return 0
finish
