Trình Biên Dịch Ngôn Ngữ AveraThe Avera Programming Language

Avera là ngôn ngữ lập trình hệ thống biên dịch trực tiếp ra mã máy (AOT) qua Cranelift, với cơ chế an toàn bộ nhớ tĩnh không dùng GC qua MIR dataflow và hệ thống Magnet.Avera is an ahead-of-time (AOT) native systems language compiled via Cranelift, featuring GC-free static memory safety through MIR dataflow and the Magnet system.

Sơ đồ pipeline biên dịchCompiler Pipeline

.av/.mav source → Lexer → Parser (AST) → Resolver → TypeChecker → Ownership/Borrow/Magnet (MIR) → Drop Elaboration → Cranelift IR → .o → Linker

Toàn bộ quá trình này diễn ra tĩnh (compile-time), không có Virtual Machine hay Garbage Collector.

This entire pipeline is static (compile-time). There is no VM or GC.

Biên dịch AOT nativeAOT Native Compilation

Cranelift sinh file object .o từ IR. System linker (như cc) liên kết thành file thực thi native.

Cranelift emits .o object files. A system linker (like cc) produces the final native binary.

An toàn không cần GCGC-Free Safety

Kiểm tra tĩnh (static checks) ngăn chặn truy cập vùng nhớ sau khi chuyển quyền sở hữu (use-after-move) và tự động giải phóng (drop) đúng thời điểm.

Static checks prevent use-after-move errors and automatically insert safe deallocations (drops) at the right time.

Hệ thống MagnetMagnet System

Lưu giữ liên kết (retained route) tới storage thực sự, đảm bảo an toàn tĩnh khi tương tác gần với phần cứng hoặc hệ điều hành.

Retains a route to physical storage, guaranteeing static safety while allowing low-level interactions.
