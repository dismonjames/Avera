Cài đặt & Chạy thửGetting Started

Hướng dẫn cài đặt trình biên dịch Avera và viết chương trình đầu tiên.Guide to installing the Avera compiler and writing your first program.

1. Yêu cầu hệ thống1. Prerequisites

Avera biên dịch trực tiếp ra mã máy và cần một C Linker trên hệ thống để đóng gói thành file thực thi.

Avera compiles ahead-of-time and requires a C Linker on your system to link the final executable.

  • Linux / macOS: gcc, clang, hoặc cc (thường có sẵn hoặc cài qua build-essential / Xcode Build Tools).
  • Windows: MSVC (Visual Studio C++ Build Tools) hoặc MinGW/GCC.

2. Cài đặt nhanh (Pre-built Binaries)2. Quick Install (Pre-built Binaries)

Cách nhanh nhất để dùng Avera là cài đặt bản build sẵn cho Linux, macOS hoặc Windows.

The fastest way to use Avera is to install the pre-built binaries for Linux, macOS, or Windows.

Linux / macOS (amd64 & arm64)

Terminal
curl -sSL https://raw.githubusercontent.com/dismonjames/Avera/main/install.sh | sh

Windows (amd64 & arm64)

PowerShell
irm https://raw.githubusercontent.com/dismonjames/Avera/main/install.ps1 | iex

3. Build từ mã nguồn (Dành cho Dev)3. Build from Source (For Devs)

Terminal
git clone https://github.com/dismonjames/Avera.git
cd Avera

# Build release binary
cargo build --release

# Xác nhận binary
./target/release/avera version

4. Hello World4. Hello World

Tạo file hello.av. Sử dụng từ khóa action cho hàm và cặp will...finish cho khối lệnh.

Create hello.av. Use the action keyword for functions and will...finish for blocks.

hello.av
#std.io

action main(): I32 will
    print("Hello from Avera")
    return 0
finish
Terminal
./target/release/avera run hello.av
// Output: Hello from Avera
