Cài đặt & Chạy thửGetting Started

Hướng dẫn từng bước: build trình biên dịch từ mã nguồn Rust và viết + chạy chương trình Avera đầu tiên.Step-by-step guide: build the compiler from Rust source and write your first Avera program.

1. Yêu cầu hệ thống1. Prerequisites

  • Rust stable & Cargo: cài quainstall via https://rustup.rs. Kiểm tra bằngVerify with rustc --version.
  • C linker (gcc / clang / cc): cần có trongmust be on PATH. Avera gọi linker này để ghép file object thành file thực thi native.Avera calls this linker to link the object file into a native executable.

2. Build từ mã nguồn2. Build from Source

Terminal
git clone https://github.com/dismonjames/Avera.git
cd Avera

# Build release binary (tối ưu hơn để dùng thực tế)
cargo build --release

# Xác nhận binary đã tồn tại
./target/release/avera version

3. Các lệnh CLI3. CLI Commands

Trình biên dịch cung cấp các lệnh sau (xem thêm ở trang Diagnostics):

The compiler provides these commands (see also Diagnostics):

LệnhCommandMô tảDescription
avera run <file>Build và chạy ngay file đó.Build then immediately execute the file.
avera build <files...>Biên dịch và liên kết thành file thực thi native.Compile and link into a native executable.
avera check <files...>Chỉ kiểm tra type-check và ownership, không sinh mã.Type-check and ownership-check without emitting code.
avera fmt <files...>Format lại mã nguồn. Thêm --check để chỉ kiểm tra.Format source code. Use --check to only verify formatting.
avera test <dirs...>Biên dịch và chạy test.Compile and run tests.
avera explain <CODE>Giải thích chi tiết một mã lỗi, ví dụ: avera explain E4001Explain a diagnostic error code, e.g. avera explain E4001
avera cleanXóa thư mục build/ chứa artifact.Remove the build/ artifact directory.

Tùy chọn cho lệnh buildBuild options

  • -O0, -O1, -O2, --opt: mức tối ưu hóa.optimization level.
  • --emit ast / typed-ast / mir / clif / obj: chọn định dạng output trung gian để debug.choose intermediate output format for debugging.

4. Chương trình đầu tiên: Hello World4. First Program: Hello World

Tạo file hello.av. Dòng #std.io là directive import module I/O chuẩn. Hàm main phải trả về I32.

Create hello.av. The #std.io line is a directive that imports the standard I/O module. The main action must return I32.

hello.av
#std.io

action main(): I32 will
    print("Hello from Avera")
    return 0
finish
Terminal
./target/release/avera run hello.av
# Output: Hello from Avera
Lưu ý về cú phápSyntax Note

Trong Avera, khối lệnh (của hàm, vòng lặp, điều kiện...) mở bằng từ khóa will và đóng bằng finish, không dùng dấu ngoặc nhọn {}.

In Avera, statement blocks (for functions, loops, conditionals...) open with keyword will and close with finish. There are no curly braces {}.
