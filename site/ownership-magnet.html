Ownership, Borrow, Magnet & AddressOwnership, Borrow, Magnet & Address

Avera có 4 khái niệm riêng biệt về bộ nhớ:

Avera has 4 distinct memory concepts:

  • Ownership: Ai đang sở hữu dữ liệu (và chịu trách nhiệm dọn dẹp).Who owns the data (and is responsible for cleanup).
  • Borrow: Quyền truy cập tạm thời an toàn (không lấy ownership).Safe temporary access rights (without ownership).
  • Magnet: Liên kết được lưu giữ (retained route) tới storage cụ thể.Retained route to a specific storage location.
  • Address<T>: Địa chỉ máy thuần, không có safety check.Raw machine address, no safety checks.
  • raw: Vùng mã compiler không thể chứng minh safety.Code blocks where the compiler cannot prove safety.

1. Ownership1. Ownership

Mọi giá trị đều có một Owner. Khi gán (assignment), ownership được chuyển đi (Move) và biến cũ không thể sử dụng nữa.

Every value has an Owner. On assignment, ownership is moved and the old variable can no longer be used.

ownership.av
::msg = "hello"
:target = ^msg        // msg bị moved

// print(msg)         // LỖI: msg không còn sở hữu dữ liệu

Drop Elaborator tự động chèn mã giải phóng khi owner ra khỏi scope (ví dụ: tự động free chuỗi Text, nhưng không chèn gì vào shape nằm trên stack).

Drop Elaborator automatically inserts cleanup code when the owner goes out of scope (e.g. automatically frees Text strings, but does nothing for stack-allocated shapes).

2. Borrow2. Borrow

Borrow (&, &!) có scoped, tuân thủ quy tắc độc quyền (xor): tại một thời điểm, chỉ được phép có nhiều & HOẶC một &!.

Borrows (&, &!) are scoped and follow the xor rule: at any time, you may have multiple & OR exactly one &!.

3. Hệ thống Magnet (~)3. Magnet System (~)

Magnet là một "đường ống" trỏ tới storage thật của biến. Trình biên dịch cấm di chuyển (move) hoặc giải phóng (drop) target nếu vẫn còn Magnet đang trỏ tới nó.

A Magnet is a "route" to the actual storage of a variable. The compiler prevents moving or dropping the target if there is a live Magnet pointing to it.

magnet_safety.av
::x = 10
~m = x

// :y = ^x           // LỖI: Không thể move x vì m vẫn đang trỏ tới nó
// x!                // LỖI: Không thể drop x sớm vì m đang live

Cú pháp MagnetMagnet Syntax

magnet_syntax.av
// Trích xuất metadata
~m.address          // Trả về kiểu Address
~m.span             // Lấy kích thước (size)
~m.offset           // Lấy offset hiện tại

// Thao tác với Magnet (Pointer arithmetic điều khiển storage)
~m += n             // Dịch Magnet đi n bytes
~m -= n

// Lưu ý: m += n (không có dấu ~) mang ý nghĩa mutate giá trị của biến target (nếu nó là số).

4. Raw & Address<T>4. Raw & Address<T>

Các khối raw được dùng khi thao tác trực tiếp với Address<T> (con trỏ C-style).

raw blocks are used when directly manipulating Address<T> (C-style pointers).
