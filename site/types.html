Kiểu Dữ LiệuData Types

Toàn bộ hệ thống kiểu của Avera: kiểu nguyên thủy, shape (struct), choice (enum), kiểu Borrow, kiểu Magnet, và các kiểu tổ hợp.Avera's complete type system: primitives, shape (struct), choice (enum), Borrow types, Magnet types, and composite types.

1. Kiểu nguyên thủy (Primitives — built-in)1. Primitive Types (built-in)

The following types are provided by the compiler runtime and require no import:

2. Shape (kiểu tổ hợp tương tự struct)2. Shape (like struct)

Dùng từ khóa shape để định nghĩa kiểu có nhiều trường. Khai báo trường bằng name: Type. Khởi tạo bằng TypeName(val1, val2).

Use the shape keyword to define a record type with named fields. Fields use name: Type. Instantiate with TypeName(val1, val2).

shape.av
shape User will
    name: Text
    age:  I32
finish

# Khởi tạo shape
:me = User("Alice", 30)

# Truy cập trường
print(me.name)
print(me.age)

Method có thể định nghĩa ngoài shape với cú pháp action TypeName.method_name(self_param, ...):

Methods can be defined outside the shape using action TypeName.method_name(self_param, ...):

shape.av
action User.greet(u: User): I32 will
    print("User:", u.name, "age:", u.age)
    return 0
finish

# Gọi method
me.greet()

3. Choice (kiểu tổng quát tương tự enum)3. Choice (like enum)

choice là kiểu tagged union — một giá trị chỉ có thể là một trong các variant đã định nghĩa. Dùng match để phân biệt variant.

choice is a tagged union — a value can only be one of the defined variants at a time. Use match to distinguish variants.

choice.av
choice Shape will
    Circle(radius: F64)
    Rect(width: F64, height: F64)
    Point
finish

:s = Shape.Circle(5.0)

match s will
    Circle(r)    => print("Circle radius:", r)
    Rect(w, h)   => print("Rect", w, h)
    Point        => print("just a point")
finish

4. Kiểu Generic4. Generic Types

Shape, choice và action đều hỗ trợ tham số kiểu generic:

Shape, choice and action all support generic type parameters:

generic.av
shape Pair will
    first:  A
    second: B
finish

:p = Pair(1, "hello")

choice Maybe will
    Some(value: T)
    None
finish

5. Kiểu Borrow (&T)5. Borrow Types (&T)

Borrow cho phép tham chiếu đến một giá trị mà không lấy ownership:

A borrow is a reference to a value without taking ownership:

Syntax
&T      # Shared borrow — chỉ đọc, nhiều borrow cùng lúc được phép
&!T     # Mutable borrow — đọc/ghi, tại một thời điểm chỉ có 1 mutable borrow

action print_user(u: &User) will
    print(u.name)
finish

6. Kiểu Magnet (~T)6. Magnet Types (~T)

Magnet pointer gắn trực tiếp vào địa chỉ runtime thực của biến. Xem chi tiết ở trang Ownership & Magnet.

Magnet pointer attaches to the live runtime address of a variable. See Ownership & Magnet for full details.

Syntax
~T      # Immutable magnet pointer to T
~!T     # Mutable magnet pointer to T

8. Ability (Interface/Trait)8. Ability (Interface/Trait)

ability định nghĩa một tập hợp các hàm mà một kiểu phải implement:

ability defines a set of functions that a type must implement:

ability.av
ability Printable will
    action show(self: &Self): Text
finish

implement Printable for User will
    action show(self: &User): Text will
        return self.name
    finish
finish

9. Foreign (FFI với C)9. Foreign (C FFI)

Khai báo hàm C để gọi từ Avera, dùng directive #header và block foreign:

Declare C functions callable from Avera using #header directive and foreign block:

ffi.av
#header "stdio.h"

foreign "C" will
    action printf(fmt: &Text, ...): I32
finish

action main(): I32 will
    printf("hello from C\n")
    return 0
finish
