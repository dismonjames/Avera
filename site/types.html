3. Shape (Struct)3. Shape

shape phân bổ trên stack hoặc inline mặc định. Không dùng heap trừ khi bọc trong Box.

shape instances are stack or inline allocated by default. No heap usage unless wrapped in Box.

shape.av
shape Point will
    x: F32
    y: F32
finish

MethodsMethods

Method yêu cầu truyền self tường minh (e.g. &self, &!self, ^self).

Methods require explicit self passing (e.g. &self, &!self, ^self).

method.av
action Point.shift(&!self, dx: F32) will
    self.x += dx
finish

4. Choice (Enum)4. Choice

Kiểu Tagged Union (cũng nằm trên stack mặc định). Truy cập variant qua .variant_name.

Tagged Union type (also stack allocated by default). Access variants via .variant_name.

choice.av
choice Maybe will
    Some(value: T)
    None
finish

:val = Maybe.some(10)

5. Foreign (C FFI)5. Foreign (C FFI)

Giao tiếp với C yêu cầu dùng các kiểu chuẩn xác về bộ nhớ (không tự ý cast &Text thành char*).

Interfacing with C requires accurate memory types (do not arbitrarily cast &Text to char*).

ffi.av
foreign "C" will
    action puts(s: Address): I32
finish
