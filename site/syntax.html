Cú pháp & Câu lệnhSyntax & Statements

1. Khai báo biến (Owner Binding)1. Variable Declarations

Avera dùng : cho biến thay đổi được ownership và :: cho biến bất biến (immutable owner). Không dùng từ khóa let hay var.

Avera uses : for standard owner bindings and :: for immutable owners. There are no let or var keywords.

Syntax
:name = expr              // Khai báo biến, tự suy luận kiểu
:name: Type = expr      // Khai báo có kiểu tường minh
::name = expr           // Khai báo biến bất biến (immutable owner)
Example
:x = 42
::PI = 3.14159          // PI không thể bị mutate sâu hay lấy mutable borrow (&!)

2. Hàm (Action)2. Functions (Actions)

Khối hàm mở bằng will và đóng bằng finish.

Function blocks open with will and close with finish.

Example
action add(a: I32, b: I32): I32 will
    return a + b
finish

3. Điều kiện (If / Else)3. Conditionals

Chỉ có một từ khóa finish ở cuối chuỗi điều kiện.

There is only one finish keyword at the end of the conditional chain.

Syntax
if n % 15 == 0 will
    print("FizzBuzz")
else if n % 3 == 0 will
    print("Fizz")
else
    print(n)
finish

4. Vòng lặp4. Loops

Example
// While loop
while i < 10 will
    i += 1
finish

// Loop (vô hạn)
loop will
    break
finish

// For loop
for i in 1..10 will
    print(i)
finish

5. Match5. Match

Syntax
match value will
    .some(x) => print(x)
    .none    => print("Empty")
finish
