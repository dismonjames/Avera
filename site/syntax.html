Cú pháp & Câu lệnhSyntax & Statements

Toàn bộ cú pháp câu lệnh, biểu thức, toán tử và khai báo hàm trong Avera — trích dẫn trực tiếp từ parser.All statement syntax, expressions, operators and function declarations in Avera — extracted directly from the parser source.

1. Khai báo biến (Owner Binding)1. Variable Declarations (Owner Bindings)

Avera dùng ký hiệu : (dấu hai chấm) thay cho từ khóa như let hay var. Đây là cú pháp khai báo biến chính trong ngôn ngữ:

Avera uses the : prefix instead of keywords like let or var. This is the main variable binding syntax:

Syntax
:name = expr              # Khai báo biến, kiểu được suy ra tự động
:name: Type = expr      # Khai báo biến với kiểu tường minh
::name = expr           # Khai báo hằng số (const binding)
Example
:x = 42                  # x kiểu I32
:name: Text = "Avera"   # name kiểu Text, tường minh
::PI = 3.14159          # hằng số PI
Quan trọngImportant

Avera không có từ khóa let. Khai báo biến là :tên = giá_trị.

Avera has no let keyword. Variable declarations use :name = value.

2. Hàm (Action)2. Functions (Actions)

Hàm trong Avera gọi là action. Tham số có định dạng name: Type. Khối thân hàm mở bằng will và đóng bằng finish.

Functions in Avera are called actions. Parameters use name: Type format. The body opens with will and closes with finish.

Example
# Hàm không có tham số
action main(): I32 will
    return 0
finish

# Hàm có tham số
action add(a: I32, b: I32): I32 will
    return a + b
finish

# Hàm không có kiểu trả về (unit type)
action say_hi(name: Text) will
    print("Hi,", name)
finish

3. Câu lệnh Điều kiện (If / Else)3. Conditional Statements (If / Else)

Cú pháp if/else trong Avera: điều kiện tiếp theo là will, khối lệnh kết thúc bằng finish. Lưu ý: chỉ có một từ khóa finish ở cuối toàn bộ chuỗi if/else.

Avera if/else syntax: condition is followed by will, the entire chain closes with a single finish at the end.

Syntax
# Chỉ if
if condition will
    ...
finish

# if / else
if condition will
    ...
else
    ...
finish

# if / else if / else (một finish duy nhất ở cuối)
if n % 15 == 0 will
    print("FizzBuzz")
else if n % 3 == 0 will
    print("Fizz")
else if n % 5 == 0 will
    print("Buzz")
else
    print(n)
finish

4. Vòng lặp While / Loop4. While / Loop

Example
# While: lặp khi điều kiện còn đúng
:i = 0
while i < 10 will
    print(i)
    i += 1
finish

# Loop: lặp vô hạn, thoát bằng break
loop will
    :line = input()
    if line == "quit" will
        break
    finish
    print(line)
finish

5. Vòng lặp For / In5. For / In Loop

Vòng lặp for duyệt qua một iterator hoặc range. Range dùng cú pháp a..b.

The for loop iterates over an iterator or range. Ranges use a..b syntax.

Syntax
# Duyệt range (ví dụ từ source: for i in 1..17)
for i in 1..17 will
    print(i)
finish

# Duyệt với prefix mode
for &item in collection will       # duyệt borrow (shared)
    print(item)
finish

for &!item in collection will      # duyệt borrow mutable
    item = item + 1
finish

for ^item in collection will       # duyệt move (lấy ownership)
    process(item)
finish

6. Match (Pattern Matching)6. Match (Pattern Matching)

Match dùng để so khớp pattern trên một giá trị, thường dùng với kiểu choice (enum).

Match performs pattern matching on a value, typically used with choice (enum) types.

Syntax
match value will
    VariantName(a, b) => print(a, b)
    OtherVariant      => print("other")
    _                 => print("wildcard")
finish

9. Directive (#)9. Directives (#)

Directive bắt đầu bằng dấu #, đặt ở đầu file để khai báo module, import thư viện và cấu hình biên dịch:

Directives start with # and appear at the top of a file to declare modules, import libraries, and configure compilation:

Syntax
#std.io               # Import module I/O chuẩn
#std.core             # Import module core runtime
#std.io.*             # Import tất cả từ std.io
#std.io as io         # Import với alias

#module my.pkg        # Khai báo tên module của file này
#header "file.h"      # Include C header (dùng với FFI)
#source "file.c"      # Link C source file
#link "libname"       # Link thư viện native
#depends other.mod    # Khai báo dependency
