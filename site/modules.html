Modules & Projects (.mav)Modules & Projects (.mav)

Kiến trúc project của Avera phân tách rạch ròi giữa giao diện public và phần hiện thực thông qua các file .mav.

Avera's project architecture strictly separates public interfaces from implementation via .mav files.

Kiến trúc fileFile Architecture

  • .mav (Module Contract): Khai báo danh sách file nguồn và interface công khai (public interface).Declares source files and public interfaces.
  • .av (Implementation): Chứa mã nguồn thực thi.Contains the actual implementation code.

File .mav thay thế cho file header truyền thống và file config (như avera.toml không bắt buộc nếu dùng .mav).

The .mav file replaces traditional header files and acts as the module manifest.

sys.mav
// sys.mav
module "sys"

// Liệt kê các file .av thuộc module này
source "os_linux.av"
source "fs.av"

// Chỉ định interface công khai ra bên ngoài
export action read_file(path: &Text): Result
